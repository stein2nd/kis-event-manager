# KIS Event Manager

## 使い方

1. `wp-content/plugins/kis-event-manager` に配置し、WordPress 管理画面の「プラグイン」から有効化します。
2. 管理画面の「イベント」からイベントを登録します。イベント種別、開催日時、概要などを入力して公開してください。
3. 一覧を表示する固定ページに `[kis_event_list]` を記載します。
4. 個別イベントページは、イベント投稿のパーマリンク（`/event/`）から表示できます。表示されない場合は「設定 > パーマリンク設定」で保存し直してください。

## コード貢献

1. このリポジトリをフォークし、変更内容が分かるブランチを作成します。
2. 既存のコーディングスタイルに合わせて変更し、WordPress の管理画面と公開ページで動作を確認します。
3. コミットは目的ごとに分け、変更内容が分かるメッセージを付けます。
4. `main` ブランチへプルリクエストを作成し、変更内容、確認手順、影響範囲を記載してください。

バグ報告や改善提案は、再現手順と期待する動作を添えて Issue でお知らせください。
